# 页面、按钮与交互有效性检查

## Goal

对当前 Next.js 应用执行一次独立的页面、导航、按钮、表单和关键业务流程有效性检查，产出可复核的缺陷与未验证项报告；本任务不修复产品代码。

## Requirements

- 覆盖公开页、登录、引导、Home、Plan、Profile、Concern、Paywall、Checkout Return 及公共导航。
- 为每个可操作控件记录前置条件、触发行为、预期结果和实际结果。
- 使用 ego-browser 检查真实本地运行页面，覆盖桌面和 390px 移动视口；验证键盘焦点、链接目标、按钮可用性、提交中状态和错误反馈。
- 覆盖未登录、已登录无资料、已登录有资料、免费用户和已付费用户适用的访问控制与重定向。
- 覆盖登录、创建/更新资料、任务完成、check-in、concern 操作、导航和结账发起/回跳状态；不创建真实订单、不退款、不清空登录状态。
- 使用独立测试账号或当前可用的测试会话；无法取得会话时必须明确记录阻塞，不绕过鉴权。
- 缺陷按严重度分级，报告包含复现步骤、预期/实际结果、证据和影响范围；修复另建任务或归入现有任务。
- 保留现有未提交改动，不修改业务代码、数据库 schema 或支付数据。

## Acceptance Criteria

- [ ] 所有目标路由均有检查结果：通过、失败或未验证，并注明原因。
- [ ] 所有主要链接、按钮和表单控件均有可追溯检查记录。
- [ ] 桌面与 390px 视口下无核心控件被遮挡、无法点击或横向溢出。
- [ ] 关键流程的成功、加载、失败、无权限和重定向结果均有证据。
- [ ] 任务完成后生成检查清单和按严重度分级的报告，且未改动产品代码或用户既有工作区改动。

## Notes

- 本任务是独立回归检查，不替代现有视觉改版或计划页功能任务。
- 真实支付、退款、生产数据写入和破坏性账号操作明确排除。
